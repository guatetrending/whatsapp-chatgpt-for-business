# WhatsApp CRM Helper Chrome Extension

This experimental Chrome extension lets you store a small contact list and send personalized messages to those contacts on WhatsApp Web.

**How it works**

1. Open WhatsApp Web in Chrome.
2. Click the extension icon to open the popup.
3. Add contacts with a name, phone number and a message template.
4. Press **Send** next to a contact to open a chat and send the message using the template.

Messages are sent by navigating to the chat using the WhatsApp Web URL scheme and simulating a click on the send button.

> **Note**: This extension is for demonstration purposes only. It is not an official WhatsApp product and may violate WhatsApp's Terms of Service. Use it at your own risk.
